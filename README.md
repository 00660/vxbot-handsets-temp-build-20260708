# iBox Native Android

这是 iBox 5000 面板的独立原生 Android 客户端。APK 内没有 WebView 面板页面，主导航、账号、合成、行情、量化、交易、抽奖、首发和设置均使用 Android 原生控件绘制。

当前版本包含：

- 服务地址持久化和离线可打开的原生连接页
- 短信登录流程与独立 Geetest 验证窗口
- 账号资产读取、刷新、切换和移除
- 合成活动、立即合成、定时任务和取消
- 行情搜索、阈值监控、停止监控
- 量化策略配置、启停、删除、记录、人机验证和支付入口
- 交易/捡漏任务创建、启停、删除、支付入口和人机验证
- 首发立即/定时任务、取消、钱包支付入口和人机验证
- Bark 配置和测试
- 可选的 Android 前台状态同步通知，每 60 秒读取任务状态

APK 是原生客户端，业务数据和任务执行仍通过可配置的 `/api/ibox/v304` 服务地址访问；默认地址是 `http://192.168.2.204:5000`。要在外网使用，需要把设置中的地址改为设备可访问的 HTTPS 或内网穿透地址，不能把 `192.168.2.204` 当成公网地址。

远端构建使用 GitHub Actions，运行环境为 JDK 21、Gradle 8.9、Android Gradle Plugin 8.7.3、compileSdk 35。构建产物为 `app/build/outputs/apk/debug/app-debug.apk`。
